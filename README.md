# Hole in the Wall (HITW)
This game is a remake of MCC's minigame hole in the wall, but this version will have better; graphics, content, and physics.

Week 1:
Added 9 more wall variants, crouch mechanic, and altered the player physics. Added a pause, options, and title screen menus.

Demo is available on itch however it is currently at a very early stage in development:
https://alloymvp.itch.io/hitw

Instructions on how to play are in the description on itch.
